All six practice-area images are generated thematic compositions and are strictly marked **`TEMPORARY`** in code (`src/data/services.ts`) and in this document only. The public `alt` text does not carry a temporary or illustration label.

### Why they are temporary

In the prototype file `rivora-handoff-generator/src_inputs/code.html`, Practice Area links 2 through 6 pointed to private Google Aida session links (`https://lh3.googleusercontent.com/aida/ALJJyr...`) which return HTTP 302 login redirects to `accounts.google.com/v3/signin` in unauthenticated sessions. Slide 1 in `screen.png` captured an unloaded placeholder box. No raster master files were included in the project archives. Clean thematic compositions were therefore synthesized so the site can be tested, delivered responsively, and laid out without 404s or layout shift.

## 3. Client Photo Request — Six Practice Areas

Please supply one licensed, landscape photograph per practice area. Use these exact practice-area names in the delivery folder and in any captions:

1. **Due Diligence** — Licensed cadastral survey or village FMB sheet showing survey numbers and boundary traverse lines, photographed flat on a counsel's desk.
2. **Pre-Litigation** — A client consultation in a law chamber with a property file, marked boundary map, and counsel taking notes.
3. **Documentation** — A registered sale deed on stamp paper with an advocate's seal and signing pen at a sub-registrar desk.
4. **Institutional** — A corporate boardroom review of a large land-parcel dossier with site plans and advisors present.
5. **Contract Drafting** — A drafting desk with a joint-development or lease agreement, a fountain pen, and red-ink amendments.
6. **Litigation Support** — A High Court advocate's bench or courtroom with case files and counsel preparing a title-defect argument.

**Delivery specification:** 1440 × 700 px minimum, landscape ~2:1, dark/warm colour tones preferred, licensed for web use. Save/overwrite the files directly into `src/assets/images/practice-01.png` through `practice-06.png`, then run:

```bash
npm run images
npm run build
```

Sharp will regenerate all AVIF, WebP, and JPEG responsive sizes (480, 768, 1100, 1440w) in `public/images/`. `npm run images` only reads the masters; it never overwrites them. To rebuild the current code-generated artwork instead, run `npm run art` first.
